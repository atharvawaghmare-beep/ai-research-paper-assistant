# Full-Stack Vite + FastAPI Starter

This workspace contains a React frontend built with Vite and Tailwind CSS, plus a FastAPI backend using PostgreSQL with SQLAlchemy ORM.

## Structure

- `frontend/` React, Vite, React Router, Tailwind CSS
- `backend/` FastAPI, SQLAlchemy, PostgreSQL, service-oriented backend layout
- `docker-compose.yml` PostgreSQL container for local development

## Frontend

```bash
cd frontend
npm install
npm run dev
```

Set `frontend/.env` from `frontend/.env.example` before running.

## Backend

```bash
cd backend
pip install -e .
alembic upgrade head
uvicorn app.main:app --reload
```

Set `backend/.env` from `backend/.env.example` before running.

## Database

```bash
docker compose up -d postgres
```

The backend expects PostgreSQL to be available at the `DATABASE_URL` configured in `backend/.env`.

Schema is managed by Alembic migrations under `backend/alembic/versions/`, not by the app at runtime. After changing a SQLAlchemy model:

```bash
cd backend
alembic revision --autogenerate -m "describe the change"
alembic upgrade head
```

Always review an autogenerated migration before applying it.

## Notes

- The frontend expects the API base URL in `VITE_API_BASE_URL`.
- The backend no longer creates tables on startup — run `alembic upgrade head` first.
